# Deliverable format — Announcement coverage report

Two deliverables come out of this skill: a **.docx report** and a **separate
email**. Both are built from the same analysis. Match the structure and tone of
the reference file `EAS Monitoring Report_5.26.26.docx` exactly.

## File naming

Convention: **`[Code] Monitoring Report_[M.DD.YY].docx`**
(e.g., `EAS Monitoring Report_5.26.26.docx`). Get the `[Code]` and date from the
analyst in the interview. The email file mirrors the name with an `_email` suffix
(e.g., `EAS Monitoring Report_5.26.26_email.txt`).

## The email (separate file)

A short, paste-into-Outlook message. Keep it to the snapshot only — the full
analysis lives in the docx attachment.

```
Subject: [Code] Monitoring Report – [Announcement topic] – [M.DD.YY]

Dear Colleagues,

Below is an initial snapshot of media coverage of [topic]. Overall, [one-sentence
read on how media received it].

A full pulse report on media and digital coverage will follow later this week.
[Paywalled full text articles are attached, if applicable.]

[2–4 Coverage Takeaways bullets — same as the docx.]

Best,
[Analyst]
```

## The .docx report — section order

Build in exactly this order (it mirrors the reference deliverable):

1. **Greeting + snapshot** — "Dear Colleagues," then the 2–3 sentence snapshot,
   then the "A full pulse report… will follow" line and the attachments note.

2. **Coverage Takeaways** — 2–4 narrative bullets synthesizing the data: what
   coverage centered on, the dominant messages and durability angle, sentiment
   lean, and 2–3 verbatim outlet quotes (pull from `Title` / `Hit Sentence`,
   attributed to the outlet, e.g., New York Times noting "…"). This is the
   qualitative heart of the report — write it from the actual articles, not
   boilerplate.

3. **Key Message Pull Through** — bullets in the fixed format `XX% – [message]`.

4. **Sentiment Analysis** — heading (bold) then the `sentiment.png` chart.

5. **Type of Coverage by Reach** — heading then `reach.png`. If `analyze.py`
   produced a `reach_footnote`, add it as small italic text below the chart.

6. **Social Media Volume Breakdown** — heading then `social_volume.png`.
   (Omit if there's no social data.)

7. **Competitor Share of Voice** — heading then `sov.png`. Congresses only / when
   requested; omit for a plain Announcement.

8. **Top News** — the snapshot line, then tiered sub-headings (Top Tier,
   Investor Influence, Industry/General Trade & Policy, General Population,
   OUS/Global Media), each with `Outlet: Headline` bullets.

## Formatting notes

- Section headings: bold (the reference underlines them — match that).
- Charts: insert the PNGs at ~6.5" wide, centered, captionless (the heading is
  the caption).
- Keep the voice factual and measured — "encouraging early-stage data rather
  than overstated" is the register, not marketing hype.
- Build the .docx with the `docx` skill for clean styling; insert the chart PNGs
  generated by `make_charts.py`.
